# Мой английский — игры по словам с репетитором

Локальный сайт для повторения слов из переписки с репетитором в Telegram.
1705 слов (август 2024 — сентябрь 2026) вытащены из экспорта чата.

## Запуск

Двойной клик по `index.html`, и сайт откроется в браузере. Сервер не нужен.

## Что внутри

- **🗓️ Трекер повторений.** Берёт группу слов (10–30), назначает повторения через 1, 3, 7, 14 и 30 дней
  и показывает, сколько слов повторить сегодня и что будет в ближайшие 30 дней.
  Ошибка отправляет слово обратно на интервал «1 день».
  Когда вся группа прошла недельное повторение, открывается следующая группа.
- **🃏 Карточки.** Перевернул, вспомнил, отметил «знаю / не знаю». Работают EN→RU и RU→EN.
- **✅ Квиз.** 10 вопросов, в каждом 4 варианта ответа.
- **🪢 Виселица.** Угадываешь английское слово по переводу.
- **🎧 Аудирование.** Слушаешь слово (есть медленный режим 🐢) и пишешь его. Ошибки подсвечиваются по буквам.
- **🧩 Вставь слово.** В предложении пропущено слово: впиши его сам или открой 4 варианта.
- **🎙️ Speak off the cuff.** Крути рулетку: она выдаёт тему для монолога с вопросом и подсказками.
  В настройках (⚙️) выбирается уровень (B2, C1, C2) и категории тем: работа, общество, фильмы и кино, аниме, еда,
  путешествия, технологии и другие. Можно выбрать одну категорию, несколько или все.
  Там же включается **напоминание в Telegram**: время и дни недели. Если в этот день запись уже отправлена, бот не напоминает.
  Для напоминания нужен внешний планировщик (см. «Напоминание для Speak off the cuff» ниже).
  Темы не повторяются, пока не выпадут все темы выборки, потом круг начинается заново. Историю можно сбросить в настройках.
  «Start» включает микрофон и таймер на 2 минуты. После двух минут таймер продолжает идти, запись останавливаешь кнопкой «Stop».
  Запись приходит голосовым сообщением в Telegram-бота (нужна настройка из раздела «Telegram» ниже), её также можно скачать.
  Темы лежат в `js/cuff-topics.js`, около 100 на уровень. Они составлены по темам устной части экзаменов
  Cambridge B2 First, C1 Advanced и C2 Proficiency, плюс свои категории вроде аниме и кино.
- **📘 Грамматика.** Одно правило в неделю в порядке учебника American English File 5 (юниты 1A–10B, 20 тем).
  Сначала объяснение на русском с примерами, потом 10 упражнений с проверкой: выбрать вариант или вписать форму.
  Ответ засчитывается без учёта регистра и сокращений (*hadn't* = *had not*).
  Когда правило недели пройдено, в понедельник открывается следующее. Можно взять его и раньше.
  «Смешанная тренировка» собирает упражнения из пройденных правил: сначала давно не повторённые и те, где были ошибки.
  Темы и порядок взяты из оглавления учебника, а объяснения и упражнения написаны для приложения (`js/grammar-rules-*.js`).
  Прогресс синхронизируется между устройствами.
  **Материалы учебника.** В разделе «📕 Учебник» можно загрузить свой файл `book.json` с Grammar Bank и упражнениями
  Grammar Bank и Workbook. Тогда у каждого правила появится вкладка со страницей Grammar Bank и кнопка «Упражнения из учебника».
  Проверяются они так же: выбор варианта, «впиши форму», «исправь выделенное» и «перепиши предложение».
  У заданий «перепиши предложение» можно засчитать свой вариант, если он не совпал с образцом.
  Учебник защищён авторским правом, поэтому файл не входит в репозиторий и сайт (`book.json` в `.gitignore`).
  Он хранится только в браузере и в твоём Upstash за ключом синхронизации (`/api/book`), так что на других устройствах появится сам.
- **📖 Словарь.** Все слова с поиском, транскрипцией и примерами.
- **➕ Добавить слова.** Вставь сообщение с новыми словами в том же формате, что присылает репетитор
  (`📎word /ipa/ - перевод`, строка `✅пример` под словом, или просто `word - перевод`).
  Проверь список и нажми «Добавить»: слова сразу появятся во всех играх и попадут в следующую группу трекера.
  Добавленные слова хранятся в браузере и входят в резервную копию прогресса, удалить их можно в словаре (🗑).

**Период 📅** выбирается кнопкой справа вверху и действует во всех играх. Можно выбрать «с августа», один месяц,
последние 30 дней, свои даты или «только трудные слова». Трудными становятся слова, в которых ты ошибся в любой игре.

**Примеры.** ✎ — пример из переписки. 💡 — пример, который написал Claude: у большинства слов в чате примера не было.
Поправить или заменить примеры Claude можно в `data/examples.json`, затем запустить `python scripts/extract_words.py`.

Прогресс хранится в браузере (localStorage). В трекере есть кнопки
«Сохранить в файл» / «Загрузить из файла» для бэкапа и переноса на другой компьютер.

## Озвучка

Сначала сайт ищет `audio/<слово>.mp3`. Если файла нет, слово озвучивает сам браузер
(лучше всего звучит в Edge: там нейросетевые голоса Microsoft).
Чтобы везде был одинаково хороший голос, сгенерируй mp3 один раз:

```
pip install edge-tts
python scripts/make_audio.py
```

Это около 3400 файлов (обычная и медленная скорость), займёт несколько минут.
Чтобы озвучка появилась и на сайте в Vercel, закоммить их: `git add audio js/audio.js && git commit -m "Add audio" && git push`.
Голос по умолчанию `en-US-AriaNeural`, мужской можно выбрать через `--voice en-US-GuyNeural`.

## Новые уроки

1. Telegram Desktop → чат с репетитором → ⋮ → Export chat history (только текст, формат HTML или JSON).
2. Положи `messages*.html` (или `result.json`) в `data/raw/`.
3. Запусти:
   ```
   python scripts/extract_words.py
   python scripts/make_audio.py
   ```

Скрипт понимает строки вида `📎Word /ipa/ - перевод` и `✅пример`, а также `word - перевод` из твоих домашек.
Слова без перевода скрипт выведет в консоль. Перевод или исправление можно добавить в `data/overrides.json`:

```json
{ "enhence": { "en": "enhance", "ru": "улучшать" }, "essay topics+ useful vocab": { "skip": true } }
```

`data/raw/` в git не попадает: в чате есть личные данные.

## Деплой на Vercel

Сайт статический, собирать ничего не нужно. Настройки лежат в `vercel.json`, а `.vercelignore` отдаёт наружу только
`index.html`, `css/`, `js/` и `audio/` (скрипты и `data/` не публикуются).

1. [vercel.com](https://vercel.com) → **Add New… → Project** → Import Git Repository → `my-english-vocab`.
2. Framework Preset: **Other**. Build Command и Output Directory оставь пустыми. Нажми **Deploy**.
3. Готово: каждый push в `main` автоматически обновляет сайт.

Прогресс хранится в браузере отдельно для каждого адреса. Чтобы перенести прогресс и добавленные слова
с локальной копии на сайт, сохрани его в файл в трекере («💾 Сохранить в файл»), а на сайте нажми «📂 Загрузить из файла».

## Telegram: бот, напоминания и приложение внутри Telegram

- **Напоминания.** Каждый вечер (19:00–20:00 по Новосибирску) бот присылает слова, которые пора повторить,
  и кнопку «▶️ Начать повторение». Если повторять нечего, бот молчит. Команда `/today` показывает, что на сегодня.
- **Mini App.** Сайт открывается прямо в Telegram: кнопкой «Учить» у поля ввода в чате с ботом или кнопкой в напоминании.
  Внутри Telegram вход без ключа, цвета темы Telegram, системная кнопка «назад», вибрация на ответах.
- **Синхронизация.** Прогресс, трудные и добавленные слова одни и те же на сайте, в телефоне и в Telegram.

Бот личный: он привязывается к тебе одноразовой ссылкой, а посторонним ничего не показывает.
Всё это работает только на сайте в Vercel.

Настройка (один раз):

1. **Бот.** В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и получи токен.
2. **Хранилище.** Vercel → проект → **Storage** → Create Database → **Upstash for Redis** (бесплатный план) →
   подключи к проекту. Нужные переменные окружения добавятся сами.
3. **Переменные.** Vercel → проект → Settings → **Environment Variables**:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `SYNC_KEY` — любой длинный пароль, придумай сам: это ключ к твоему прогрессу;
   - необязательно: `CRON_SECRET` (любая строка, защищает запуск напоминаний) и `TIMEZONE` (по умолчанию `Asia/Novosibirsk`).
4. **Redeploy:** Deployments → ⋯ → Redeploy, чтобы переменные применились.
5. На сайте открой **Трекер → ☁️ Синхронизация и Telegram**, введи `SYNC_KEY` и нажми «Подключить».
6. Нажми **«🤖 Подключить бота»** → «Открыть в Telegram» → **Start**. Бот ответит «Готово!», и у него появится кнопка «Учить».
7. Нажми «📨 Проверить Telegram»: должно прийти сообщение.
8. Телефонный браузер можно подключить кнопкой «📱 Подключить телефон», но проще открывать приложение прямо в Telegram.

Время напоминания задаётся в `vercel.json` (`"schedule": "0 12 * * *"` — это 12:00 UTC = 19:00 в Новосибирске).
На бесплатном плане Vercel cron срабатывает в пределах указанного часа.

Озвучка внутри Telegram на Android может не работать через браузерный синтез речи.
Сгенерируй mp3 (см. «Озвучка»), тогда звук будет везде.

### Напоминания в выбранное время

Время и дни недели настраиваются отдельно для трёх напоминаний:
- **слова**: Трекер → «☁️ Синхронизация и Telegram» → «🔔 Когда напоминать о словах». Бот пишет, только если есть слова к повторению;
- **грамматика**: экран «Грамматика» → «🔔 Напоминание в Telegram». Бот не пишет, если правило недели уже разобрано;
- **Speak off the cuff**: ⚙️ → «🔔 Напоминание в Telegram». Бот не пишет, если в этот день запись уже отправлена.

В конце каждого напоминания бот добавляет мемную «цитату Джейсона Стэтхэма» (`api/_quotes.json`, 581 штука, собраны со stathamcitaty.ru).
Цитаты не повторяются, пока не будут отправлены все. В трекере их можно выключить или оставить только без мата.

Пока время для слов не настроено, их по-прежнему присылает ежедневный Vercel Cron (около 19:00–20:00 по Новосибирску).
Vercel Cron на бесплатном плане срабатывает не чаще раза в день, поэтому в выбранное время напоминания присылает
бесплатный [cron-job.org](https://cron-job.org): раз в 5 минут он дёргает сайт, а сайт сам решает, кому пора напомнить.

1. Vercel → Settings → Environment Variables: задай `CRON_SECRET` (длинная строка из букв и цифр), если его ещё нет, и сделай Redeploy.
2. Зарегистрируйся на [cron-job.org](https://cron-job.org) → **Create cronjob**:
   - URL: `https://<твой-сайт>.vercel.app/api/reminders?tick=1&secret=<CRON_SECRET>`
     (старый адрес `/api/cuff-remind?tick=1&…` тоже работает);
   - Execution schedule: **Every 5 minutes**;
   - сохрани.
3. В приложении включи нужные напоминания и выбери время и дни. Через несколько минут там появится «✓ Планировщик работает».

Время считается по часовому поясу устройства, на котором ты сохранил настройки.
Если планировщик не работал больше 3 часов после выбранного времени, напоминание за этот день не придёт.
